# Python Student Management System

A beginner-friendly command-line application built with Python to manage student records.

## Features

- Add student records
- View all records
- Search by name, course, or email
- Update existing records
- Delete records
- Input validation
- Persistent storage using JSON
- Automatic student ID generation
- Exception handling for invalid input/data

## Technologies

- Python 3
- JSON
- Python standard library (`json`, `pathlib`)

## How to Run

1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:

```bash
python main.py
```

The application automatically creates `students.json` when the first student is added.
